Connect a Supabase database

Right now the app stores data in this browser only. Follow these steps to use a real database where every user shares the same issues.

  1. Create a free project at supabase.com.
  2. Open SQL Editor → New query, paste the SQL below and press Run.
  3. Open Project Settings → API and copy the Project URL and anon public key.
  4. Paste them into the two variables at the top of this file's <script> block: SUPABASE_URL and SUPABASE_ANON_KEY.
  5. Reload the page and register. The anon key is safe to expose — Row Level Security protects the data.
